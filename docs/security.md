## Honest Unresolved Security Gaps
- **Authentication on Local Control API:** Local development CORS and `/api/token` / `/api/hitl/*` endpoints do not enforce OIDC/SSO operator authentication; production deployment should place an OAuth2/JWT identity proxy ahead of FastAPI and bind `session_id` to verified operator claims.
- **Voice Confirmation Spoofing:** `classify_voice_decision()` checks utterance intent without biometric speaker verification; operators can disable voice confirmations at runtime via the **UI-Only Lock** toggle (`sadaops.set_voice_hitl` RPC), and high-risk environments should restrict confirmations exclusively to authenticated UI clicks or pin LiveKit participant identity + WebAuthn step-up.
- **Regex/Entropy Scrubber Scope:** Novel unformatted secrets shorter than 28 characters (or spoken aloud digit-by-digit) will not trigger `_is_high_entropy_secret()`.
